## Standing rules

- The hard rules live in `rules/HARD_RULES.md` (indexed in `rules/RULE_INDEX.md`) and are standing context for every session. Start there.
- [Add workspace-specific rules here, under the hard rules, in the same shape: a testable statement, and how anyone can check it. When a workspace rule becomes a standing rule for everything, promote it into `rules/HARD_RULES.md` with the next index ID.]

## Versioning

There is no version control here. Google Drive keeps the previous versions of every file (in Drive: right-click the file, then Version history), so an earlier text can always be recovered. When the rules change materially, name the new version in the change log in `rules/RULE_INDEX.md` (for example, rules v1.1, with the date) and add a dated change note at the top of the file you changed, so any session can name the rule set it is operating under.
