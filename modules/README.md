# Modules

Modules are optional rule packs. Adopt the ones that fit your work, delete the rest, and write your own in the same shape: one folder, one clear rule set, examples included.

## Included

- `workflow-gates/` — For delegating work to another AI or a person: a handoff template and a completion contract, so delegated work comes back verifiable instead of plausible.
- `evidence-standards/` — For research of any kind: how to grade sources, what counts as proof, and how to record a negative result. Ships with a genealogy-flavored example; rewrite the standards for your field.

## Writing your own module

1. Name the domain in the folder name.
2. State each rule as a testable sentence: what must be true, and how anyone can check it.
3. Include one worked example.
4. Reference the module from `core/AGENTS.md` so it loads with the core rules.
